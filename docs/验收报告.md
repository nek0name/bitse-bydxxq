# 测试与课堂演示

## 自动检查

```bash
bash scripts/build.sh
bash scripts/test.sh
```

| 测试 | 覆盖范围 |
| --- | --- |
| service-integration | 权限、钱包、并发预约、计费结算、事务回滚、HTTP、重启恢复与预测失败 |
| forecast-unit | 电量分摊、时间与天气特征、训练、冷启动、24 小时预测与站桩聚合 |
| admin-ui | 业务操作、表格筛选与复制、主题、系统偏好和异步刷新 |
| mobile-flow | 登录至结算流程、订单分页、状态条、主题与布局 |
| mobile-qml-smoke | 手机页面加载 |

脚本同时运行 C++ 格式、Ruff、Oxlint、Oxfmt 检查。构建包含 TypeScript 检查与 Vite 打包。

大屏浏览器检查需先启动服务：

```bash
uv run --with playwright python -m playwright install chromium
uv run --with playwright python web/tests/dashboard_smoke.py --url http://127.0.0.1:8080
```

浏览器测试覆盖两种尺寸、站点联动、键盘操作、空数据和断线恢复。当前界面截图位于 [design/ui](../design/ui/)。

## 演示顺序

1. 启动服务、两个客户端和大屏。管理端用 `admin / 123456` 登录，查看营收、站桩状态与预测。
2. 用户端登录并充值，选择区域、查看附近站点和驾车/步行路线。输入地址解析需配置腾讯地图 Key。
3. 选择空闲桩，预约、起充、停止并支付，查看小票；观察管理端营收和大屏同步更新。
4. 管理端新增站点、重启空闲桩、冻结与解冻用户，查看订单和操作日志。
5. 查看站点及电桩的 1/6/24 小时预测，以及[公开回测报告](../ml/reports/jiaxing/report.md)。

使用新的 `--data-dir` 可从初始状态演示，地图配置放入对应目录。
