# 初始化指南

## 工程架构

本项目采用CMake + 多子模块的工程组织架构。建议使用 VSCode + Qt Creator 作为主力编码环境，其中 VSCode 提供代码补全、符号跳转和AI功能，Qt Creator 用于可视化设计及 GDB 断点调试。顶层 `CMakeLists.txt` 配置了自动软链接，无论在 Qt Creator 中如何构建，clangd 都会保持实时索引，无需手动配置。

## 环境准备

确保本地 Linux / WSL 环境已安装工具链：

```bash
sudo apt update
sudo apt install -y build-essential cmake clangd qtbase5-dev qttools5-dev-tools libqt5charts5-dev libqt5sql5-mysql
```

接下来安装 VSCode 插件：在扩展商店安装 `clangd` 插件即可（注意不要安装微软官方的 `C/C++` 插件）。

## 首次克隆与项目初始化

只需通过 Qt Creator 完成一次项目载入与初次编译：

1. 克隆仓库：
```bash
git clone <仓库地址>
```

2. 在 Qt Creator 中打开：点击 `Open Project`，必须选中仓库最外层根目录下的 `CMakeLists.txt`（不是打开子目录）。出现配置页面时，直接点击右下角的 「Configure Project」。

3. 初次全量构建：确保左下角构建模式为 Debug，点击左下角的 锤子图标（Build） 或按下快捷键 `Ctrl + B`。此步骤会自动生成 Qt 的 `ui_*.h`、`moc_*.cpp` 并向根目录自动注入 `compile_commands.json`。

4. 启动 VS Code 编码：直接用 VS Code 打开项目根目录文件夹。打开任意 `.cpp` 文件，C++20 语法高亮与全套 Qt 补全即刻生效。

## 最佳实践

### UI 设计

1. 在 Qt Creator 的项目树中，双击对应的 `.ui` 文件，进入可视化 Designer 界面拖拽控件、调整布局并保存。
2. 在 Qt Creator 中按一次 `Ctrl + B` 构建（或者点击左下角的锤子图标）。
3. 切换回 VS Code 打开对应的 `.cpp` 文件，此时输入 `ui->` 即可直接补全刚才添加的新控件。

### Debug

1. 遇到复杂的逻辑 Bug 时，切回 Qt Creator。
2. 在代码行号左侧单击可以打断点。
3. 点击左下角 绿色虫子图标（Start Debugging / 其实直接按 F5 就行），即可在图形化变量窗口中查看 `QObject` 树结构与指针状态。

### Release

点击 Qt Creator 左下角的电脑图标，将构建模式切为 Release 并点击构建（注意选择正确的项目！）。CMake 会自动将根目录的索引切至 Release 产物，构建生成的二进制文件位于同级 Release 目录下。

## 团队协作与 Git 规范

不懂的话让 AI 来做。

建议直接使用 VSCode Git 可视化功能，或者让 AI 写 commit 进行提交。推荐装一个 gh 命令行。

提交前需要先同步，然后单独开 PR 并提交本轮更改。不要直接 commit 到 main 分支。
