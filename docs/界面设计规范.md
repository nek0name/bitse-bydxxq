# 界面设计规范

三端内置 HarmonyOS Sans SC，默认使用中性灰与低饱和靛紫。管理端与用户端支持浅色、深色和跟随系统，大屏使用石墨色背景。

| 用途 | 色值 |
| --- | --- |
| 主操作 | `#6259CA` |
| 副色 | `#8E86B8` |
| 钱包卡片 | `#30313D` |
| 浅色背景、卡片 | `#F7F7F8`、`#FFFFFF` |
| 正文、辅助文字 | `#24252B`、`#71717A` |
| 深色背景、卡片 | `#191A20`、`#23242D` |
| 深色正文、辅助文字 | `#EEEEF4`、`#B0B0BF` |
| 大屏背景、正文、辅助文字 | `#191A22`、`#F0EFF5`、`#AAA8B8` |

界面基准：[移动端](../design/ui/mobile.png) · [管理端](../design/ui/admin.png) · [大屏](../design/ui/dashboard.png) · [列筛选](../design/ui/table-filter.png) · [管理端设置](../design/ui/admin-settings.png) · [移动端设置](../design/ui/mobile-settings.png)。均为实际运行截图。

管理端从侧栏底部进入设置，用户端从“我的”进入。主色用于主要操作，副色用于导航选中、图表和局部强调。两排圆形调色盘以细外环标记选中项，修改立即生效并保存。跟随系统响应桌面主题变化。

尺寸采用逻辑像素，以 8 为主要间距、4 为微调。触控区域至少 48 × 48，正文对比度目标为 4.5:1。参考 [Material 3 布局](https://m3.material.io/foundations/layout/grids-spacing/spacing)、[Android 无障碍规范](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)与 [WCAG 对比要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 操作与表格

主操作使用实心按钮；次要操作使用文字或图标，筛选使用紧凑标签。移动端视觉尺寸与触控区域分开，触控区域至少48。用轻量卡片区分筛选、业务信息和操作分组，组内用细分隔线；表格使用直角表头与轻量行分隔。

电站与电桩卡片底部使用两端圆角的满宽细状态条。电站空闲数与价格底部对齐，导航与下方距离在卡片右上角右对齐；电桩保留左侧状态文字。电站每格对应一桩：绿色可用，灰色占用或不可用，红色故障或异常。

管理端标题、业务操作与右上角搜索共用一条工具栏，计数置于表格底部。列头点击排序，筛选图标打开当前列筛选；弹层顶部为并排升降序图标，条件与输入框同排，全选与选项搜索同排。复制使用快捷键或右键菜单，导出收进更多菜单。Ctrl+F 搜索、Esc 清空搜索并返回表格、Alt+↓筛选当前列。

## 用户端量化规则

| 项目 | 规则 | 检查方式 |
| --- | --- | --- |
| 页面边距 | 左右16；卡片内容再内缩16 | 页面标题、搜索、卡片外沿同线；卡片标题、分隔线、金额区同线 |
| 间距 | 8/16/24为主要层级；4用于图标与短标签；12用于紧凑组件 | 同类组件共用间距常量 |
| 顶部栏 | 64高；导航/右侧操作各独立48点击区 | 返回图标与标题垂直居中，窄屏标题不碰操作 |
| 底部导航 | 80高，三个等宽目的地 | 图标、选中标记及标签中心一致，点击区域互不重叠 |
| 图标 | 常规24；辅助20；操作区域至少48×48 | 返回、关闭、展开、导航、成功状态使用SVG图标 |
| 字体层级 | 页标题22，突出标题28，卡片标题16，正文14/16，辅助信息不低于12 | 同类标题字重统一，长地址可省略/换行但不压小字号 |
| 数值 | 金额、货币符号及单位沿同一基线 | 使用统一金额组件及baseline对齐 |
| 文字对比 | 常规正文及辅助文字目标至少4.5:1；灰字不能靠过低透明度形成层级 | 在浅灰/白卡背景分别计算，禁用和装饰元素单独处理 |
| 圆角 | 普通卡片16，主视觉卡片24；圆形图标容器按用途 | 同类卡片使用相同圆角 |
| 表单 | 输入与主按钮共用内容宽度；标签与输入左沿同线 | 错误不挤坏按钮，昵称输入仍保留本地草稿 |
| 操作反馈 | 点击/按下、禁用、键盘焦点可辨认，图标有Accessible名称 | Tab可定位；正在请求不可重复提交；不吞掉网络或订单错误 |
| 信息密度 | 首屏优先展示找站和操作；装饰不占据主要阅读空间 | 360×800和430×860实际运行，重要按钮可见或自然滚动到达 |

整卡进入详情与卡内导航按钮保持独立命中区域。页面提示限于费用、自动停止、待结算、
冻结、断网等操作信息。技术说明放入文档，输入限制放在标签或占位文字中。订单详情返回时保留列表位置与已加载内容，下拉刷新只更新订单。
同一状态只显示一次；成功提示居中并允许点击穿透，错误横幅从顶部滑入，新消息替换旧消息。

## 插图

登录页使用灰白电动车与灰紫充电桩插图，浅紫电缆连接车辆，在石墨色背景上保留明亮轮廓。应用加载 SVG，来源见[素材说明](../apps/user-app/assets/illustrations/README.md)。

## 大屏量化规则

| 项目 | 规则 |
| --- | --- |
| 画布 | 延续1920×1080，等比适配1366×768，并检查两种尺寸 |
| 栅格 | 区块间距16，图表内容16/24内边距，标题起始线一致 |
| 顶部指标 | 四张 KPI 高 88，主要数值字号 32，数字等宽 |
| 站点状态 | 与 KPI 同行展示各站空闲/总桩数与状态分段，使用当前API真实数据 |
| 分段口径 | 空闲=idle；在用含预约=在线减空闲；暂不可用=总量减在线 |
| 文案 | 显示连接异常、数据/预测过期及必要时间 |
| 交互 | 选中、hover、键盘focus明确，站点选择与地图同步；状态不能仅靠颜色说明 |
| 图表 | 轴、图例、工具栏不重叠，数值/单位统一，空数据/大数值/多站点有稳定显示 |

信息来源和模型评估见接口及设计文档。

## 验收方法

自动检查包含手机业务流程、全部QML页面加载、主题切换与保存和大屏浏览器验收。布局检查覆盖：
关键触控区域、金额基线、页面横向边界、顶部指标密度、新组件数据与交互。
同时人工检查各页截图的比例、对齐和文案。

界面基准位于 `design/ui/`，检查命令见[测试与演示](验收报告.md)。
